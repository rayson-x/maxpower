规律：

- 肢体明显在成像平面内且可见性好时，2D≈3D（0.5–6°），说明 3D 有 2D 证据锚定时是准的；
- **每个视频都出现单侧 10–35° 的系统性分歧**，集中在肢体有纵深旋转的一侧——单机位无法区分"3D 在纠正透视缩短"还是"z 在幻觉"，需结合指标 3 判断。

## 指标 3：z 抖动 vs xy 抖动（world 坐标，毫米/帧 @30fps）

| 关节点 | 正面引体 | 背面引体 | 斜侧划船 |
|---|---|---|---|
| 肩 (11/12) | 2.3 / 1.7 | 0.8–1.5 / 0.5–0.8 | 3.3–4.6 / 2.2–3.9 |
| 肘 (13/14) | 2.4–2.9 / 1.6–2.5 | 2.8–4.6 / 0.8–1.1 | 8.2 / 3.9 |
| 腕 (15/16) | 3.3–3.7 / 1.9–2.2 | **9.5 / 1.2** | **15.4 / 8.3** |
| 髋 (23/24) | 0.1 / 0.1 | 0.2 / 0.1 | 0.1 / 0.9 |
| 踝 (27/28) | 2.7–3.7 / 2.0–2.6 | 1.6–3.8 / 2.0–3.9 | 12.4 / 4.1 |

（z_mm / xy_mm）

**z 噪声系统性是 xy 的 2–8 倍**，远端关节（腕、踝）最严重。约 20cm 的前臂上 1cm 的 z 误差≈3° 角度噪声，实测分歧（10–35°）远大于此，说明分歧不只来自抖动，还有模型对纵深姿态的系统性误猜。

## 指标 4：可见性（遮挡代价）

- 斜侧面：整个远侧身体 visibility < 0.25（左臂 0.10–0.18），**单机位侧面丢半个身体**；
- 正面引体：左臂 visibility 0.5–0.65（器械/身体遮挡），可用帧仅 30/177；
- 背面下拉（坐姿器械）：双腿基本不可见（n=7 或 0）。

## 总体结论

1. **可信的**：骨长/骨架尺度（CV~1%）、成像平面内的关节角（2D 锚定，0.5–6°）、躯干整体姿态。做机位无关的**粗分类**（铰链 vs 深蹲、俯身程度分档）精度足够。
2. **不可信的**：依赖 z 的纵深轨迹精细评分——z 噪声 2–8× 于 xy，且存在 10–35° 系统性偏差。这印证了 `viewGating.ts` 把纵深轨迹标为"伪3D实验"的保守立场。
3. **可用性规则**（建议作为门控逻辑）：
   - 按骨向量 z 分量占比分档：肢体主要在成像平面内（z 占比小）时，3D 角可信；
   - 远侧/低 visibility（<0.5）帧直接弃用；
   - 3D 信号必须配时序滤波（z 高频抖动可滤掉一部分）。
4. 若业务上确实需要纵深精度，单目方案已触顶，需上双机位三角测量或深度硬件。
