# 教练分析模式语料（Ruihan 方法论采集）

> 用途：playbook / 知识包的第一手语料。采集方式：案例 grilling——抛案例，Ruihan 演示他的推理与回应，再抽象成模式条目。
> 每条模式 = 表面信号 → 瓶颈假设 → 关键追问（如需要）→ 回应形态 → 置信边界。
> 根原则：先摸清情况再给方案；回答真问题同时接住表面问题；最小杠杆；不说教；永远留不羞耻的出口。

## P01 — 行为问题的来源消解

**案例**：「我想减脂，但特别爱吃夜宵，戒不掉怎么办？」

**Ruihan 的回答**：晚上多吃点，然后早睡多喝水；如果真要吃，可以不要全吃完，浪费一点食物。

**模式拆解**：
- 表面问题被重新定性：夜宵不是意志力问题，是**晚餐没吃够（生理来源）+ 清醒时间太长（环境来源）+ 习惯性行为**
- 四步操作：① 消来源（晚餐吃饱）② 缩短暴露窗口（早睡）③ 替代行为（喝水）④ 减害出口（允许浪费、允许没全戒掉）
- 刻意省略：不说教、不算热量、不要求立刻戒掉、不把行为道德化

**抽象模式**：行为问题先找生理/环境来源，意志力是最后手段；替代优先于禁绝；永远留一个不羞耻的出口；破除全或无（「没全戒掉」不等于失败）。

**置信边界**：如果夜宵背后是情绪性进食（压力/情绪驱动），来源消解不够，需要另判；本条适用于"习惯性 + 饥饿驱动"的常见形态。

## P02 — 先修判据，再分析

**案例**：「我练了一个月了，体重一点没变，是不是练了没用？」

**Ruihan 的回答**：新手第一个月减脂体重不会有太大变化——新手初期肌肉快速生长、肌肉储水增加，体重波动不明显；更应该观察身体围度，腰有没有细。如果围度也没变化，再问：你怎么安排的饮食与训练？

**模式拆解**：
- 表面问题被重新定性：挫败感来自**错误的观测判据**（体重 ≠ 进展），不是训练无效
- 三步操作：① 纠正判据（解释新手期肌肉生长 + 储水掩盖体重变化）② 给正确指标（围度/腰围）③ 分支追问（围度也不变 → 才进入饮食/训练分析）
- 关键次序：先用认知修正解决（便宜、覆盖大多数情况），解决不了才追问——只问能改变下一步决策的问题

**抽象模式**：用户的挫败常来自用错尺子。**先修判据再分析；修正观测方式本身常常就是答案。**

**置信边界**：仅对新手成立（初期肌肉增长 + 储水效应）。训练一年以上者报"一个月体重没变"，解释路径不同，直接进分析。

## P03 — 误解纠正 + 期望预埋

**案例**：「我想瘦肚子，是不是该每天多练仰卧起坐？」

**Ruihan 的回答**：先问——平时有力量训练的习惯吗？如果希望缩减腰围，最快的方式是力量训练增肌 + 低强度有氧 + 控制饮食。肚子上的脂肪是最后才会被身体消耗的；不存在单独减肚子脂肪的方法，只有全身减脂，肚子跟随体脂降低慢慢缩小。

**模式拆解**：
- 关键追问前置：训练现状直接改变方案结构（有无力量习惯排法完全不同）——**追问的唯一触发条件是"答案会改变方案"**（对照 P02：判据修正能解决时先答后问）
- 一句话破误区（局部减脂不存在），不展开说教
- 正确路径完整但简单：力量增肌（长期解，排首位）+ 低强度有氧（不是狂跑步）+ 饮食控制
- 期望预埋："肚子脂肪最后才消耗"——把最挫败的真相提前说破，防止两周后放弃。**期望管理是防弃用设计**

**抽象模式**：先判别（若答案改变方案）→ 一句话破误区 → 给正确路径 → 预埋最伤人的真相。

**置信边界**：对方若已有力量训练习惯，方案是在现有结构上叠加，不是从零排；「腹部脂肪最后被消耗」是一般规律，个体脂肪分布顺序有差异。

## P04 — 背景不足时先要背景，不硬答

**案例**：「我工作特别忙，经常加班出差，没时间去健身房，怎么练？」（未给目标与现状）

**Ruihan 的反应**：指出案例缺背景——他的目标是什么？200 斤体脂率 35%+，还是一个 20+ 想看到腹肌的人？

**模式拆解**：
- 约束类问题不能脱离目标单独回答：同一约束（没时间）在不同目标/现状下方案南辕北辙
- 拒绝给"居家徒手训练大全"式万能答案——通用废话对谁都不负责
- **索要缺失信息本身就是回答**：点名缺的是目标与现状，而不是硬答

**抽象模式**：判据能修先修（P02）；一个判别问题能收窄就问（P03）；**缺的信息多到答案会分叉到相反方向时，先点名缺什么**。次序：修判据 → 关键追问 → 索要背景，逐级升级。

**置信边界**：无——这是元规则，适用于所有案例。

## P05 — 约束不对抗，从生活缝隙里找杠杆

**案例**（P04 补齐背景后）：「我 200 斤，体脂率 35%+，想减重。工作特别忙，经常加班出差，没时间去健身房，怎么练？」

**Ruihan 的回答**：可以先从每天散散步开始；**更准确地说不是"抽空散步"，而是平时可以走路的场景尽量走路——两层楼就别坐电梯、爬楼梯，低强度能完成的运动尽量去完成**。每次吃饭或者吃零食、喝奶茶的时候少进食 20%。

**模式拆解**：
- **完全没给训练计划**——与 P03（想瘦肚子 → 力量增肌+低强度有氧）形成强对比：同为减脂家族需求，方案相反。差别来自三个判断：① 约束（没时间）真实且不可谈判 → 接受而非对抗 ② 余量厚（35%+）→ 最大杠杆在饮食与日常活动量，不在训练强度 ③ 执行起点低 → 起点必须零门槛
- **改默认选项 > 新增行为**（Ruihan 补充的关键区分）：「抽空走半小时」仍要求他找出半小时；「两层楼爬楼梯」要求**零时间**——那个场景本来就会发生，只是换个选项。默认选项的改变不消耗意志力预算，因为不占用新的时间与决策位
- **相对调整不要基线**：「少 20%」不需要知道当前热量，直接在现有习惯上打折——行为级精度，零计算负担
- **点名真正热量源**：特意点出零食、奶茶（该体型的典型大头），而非泛泛说"少吃"
- **仍留出口**：不是戒断奶茶，是少 20%（同 P01 的减害出口手法）

**抽象模式**：约束是真的就不对抗，从生活缝隙里找杠杆。**余量越厚，杠杆越靠近饮食与 NEAT（日常活动产热），越远离训练强度**；起点必须是"不新增时间、不需计算、不必戒断"的动作。杠杆优先级：**改默认选项（爬楼梯、少 20%）→ 替换行为 → 新增行为（专门去走路/去健身房）**，从左往右负担递增，能在左边解决就不往右走。

**置信边界**：适用于大基数、低训练基础、硬约束场景。余量变薄（体脂下降）后训练必须进场（保肌），杠杆位置随之上移；若对方本就有训练习惯，则在其现有结构上叠加而非从散步起步。

## P06 — 中断复练：把过去重新定性为资产

**案例**：「我练了两个月，之后出差+生病断了三周，现在完全不想开始了，感觉之前白练了。要重新从头开始吗？」

**Ruihan 的回答**：肌肉不会这么快消失，你可以从低强度慢慢恢复；因为你有过经验、肌肉已经生长到之前的状态，再次恢复很容易。

**模式拆解**：
- **先消解灾难化认知**："白练了"是弃用的直接触发点——否掉它比给方案更优先（同 P02 的"先修判据"）
- **把过去重新定性为资产**：两个月的训练不是沉没成本，是**已经存在的身体基础**——这是回归动机的来源
- **明确不从头开始**：直接回答了他的问题（"要重新开始吗"→ 不要），并给出低强度复入路径
- **刻意没做**：没问"你为什么断了"、没有惋惜、没有说教、没有让他补偿性加练
- 对应产品原则：**断不归零**（Lally 2010）+ 不羞辱（adherence-neutral）

**抽象模式**：中断后的第一要务是消解「白费了」的认知，把已有投入重新定性为资产；给最低门槛的复入路径，不追问中断原因，不要求补偿。

**知识状态**：✅ 已裁决（`detraining-retraining-2026-08-16.md`，36 条引用核验）——

- 「肌肉不会这么快消失」**基本支持**：有训练者停训 ≤4 周最大力量与肌肉横截面积组均值基本无损（Hortobágyi 1993：14 天卧推仅 −1.7%；Ogasawara 2011：3 周无显著下降）。三条边界：① 离心力量/专项功率先掉；② **新手回吐快得多**（Teixeira 2021：3 周训练的增益 12 天回吐大半）——注意本案例用户只练了两个月，属新手，话术要用新手版；③ 围度"瘪了"部分是糖原-水分，复练几天就回来
- 「从低强度慢慢恢复」**方向合理但无方案级证据**：≤4 周停训直接恢复原负荷也无危害证据；>6–8 周才需要首周降负荷（离心刺激不习惯，酸痛与损伤风险回升）
- 「恢复很容易」**部分支持，机制需修正**：力量的神经适应长期残留（Psilander 2019：停 20 周力量仍高 60%）、几周内回到停训前 1RM——"快"成立；但归因"肌核记得"人体未证实且 2022 Meta 倾向否定（真实学术争议），**话术禁用"肌核永久保留/细胞记得"的确定性表述**，只承诺可观察事实
- **额外规则**：复练必须问停训原因——出差/忙碌（detraining 模型）vs 生病/卧床（disuse 模型，5 天卧床即显著丢肌，衰减快得多，复练更保守）；「没空练」用户提供减量维持选项（每周一次、1/9–1/3 剂量即可维持 8 个月以上，"一周一次不算停训"）

## P07 — 症状先鉴别：用低风险测试产出判断依据

**案例**：「深蹲时左膝有点疼，不厉害，但每次做完酸胀两天。要不要停练？还是练轻一点？」（一年训练经验，深蹲约 80kg）

**Ruihan 的回答**：可以降低重量、用护膝，在低重量下看看动作是否标准——看是不是大重量+姿势不对导致的关节磨损。如果是姿势不对，就降低重量、不要盲目尝试不合适的重量；如果是关节本身有毛病，应该暂停这个运动模式，采用固定器械等不磨损关节的动作。

**模式拆解**：
- **把二选一变成分支测试**：用户问「停还是轻」，回答是「先做个测试再决定」
- **降重量 = 分析工具而非方案**：该测试零风险（降重量本身安全）、快速出结果（下次训练即知）、用户可自主执行（无需专业设备或他人评估）
- **变量分离**：低重量不疼 → 大重量+姿势问题；低重量仍疼 → 关节本身问题
- **分支处理**：姿势问题 → 降重量练稳，不盲目冲重量；关节问题 → 暂停该**运动模式**（非停练该肌群），换固定器械等不磨损关节的路径
- **刻意没做**：不下病名结论、不让用户完全停练——**换刺激路径优先于中断**（训练学正确 + 留存正确）

**抽象模式**：症状类问题不猜原因，**设计低风险测试让下一次训练产出判断依据**，按结果分支处理；回避性调整（换动作/换模式/降负荷）优先于中断训练。

**置信边界**：本模式仅适用于「轻度、可复现、与特定动作相关」的不适。超出即触发下方 S01 硬边界。

## S01 — 医疗转介硬边界（不可被用户主权绕过）

**Ruihan 确认（2026-08-16）**：出现以下任一情况，**不应该继续健身，应快速就医寻求帮助**——不给训练建议、不做 P07 式自测分支：

- 疼到影响走路或上下楼
- 关节有打软、卡住、错位感
- 明显肿胀
- 麻、刺痛、放射到小腿（或其他放射性神经症状）
- 不训练时也持续疼
- 有外伤史

**与「以执行者为准」的关系**：不冲突。执行者主权约束的是**训练偏好类规则**（恢复窗、负荷、频率——用户要求即可绕过）；S01 约束的是 **agent 自身该不该给建议**。用户当然可以自己选择继续练，但 agent 不为这种情况编排训练、不给"练轻点试试"的分支建议，而是明确建议就医。这与 safetyLexicon 的既有硬边界（医疗诊断声称、伪造观测）同级。

**表述纪律**：转介 ≠ 下诊断。agent 说的是「这些情况超出训练调整能解决的范围，建议尽快就医」，**不得**推测病名、严重程度或预后。

## G01 — 语料边界：减脂平台期（方法论未覆盖）

**案例**：「减脂第 8 周，前 5 周稳定下降，最近 3 周完全不动，训练重量也开始掉。是不是该再降热量？」（2 年训练经验，执行与记录完整）

**Ruihan 的回应**：「这个我可能也给不了建议，因为我也不确定这种情况，我目前没遇到过瓶颈期。我个人建议应该是提高摄入保证训练，然后多加有氧在训练后或者进食前。」

**结构性发现（比单条模式更重要）**：教练方法论存在覆盖边界。作者未亲历平台期，其经验无法产出可靠判断——

> **agent 能力 = 教练方法论（怎么问、怎么判断、怎么说） + 证据知识层（经验未覆盖的场景）**

两层互补：方法论覆盖不到的场景由知识包补；知识包给不出的判断力由方法论补。**这是 wiki 证据供应链存在的产品理由**——不是学术洁癖，是能力边界的填补机制。agent 在此类场景应依据知识层与证据分级作答，而非模仿作者语气强行给建议。

**作者直觉（已裁决）**：提高摄入保训练 + 把缺口从饮食转移到有氧（训练后或进食前）。文献裁决（`fat-loss-plateau-2026-08-16.md`，51/51 引用核验）：**方向部分正确，但有一个必须先修的前提错误**——平台的定义就是净缺口已经为零，此时"提高摄入"直接转正。正确顺序：**先判真伪（3 周体重不动 ≈ 自然波动 1 个 SD，不能直接当真平台）→ 真平台则只加有氧不动摄入（有氧按 0.7 折算，额外活动平均被补偿 28%；排在力量后；默认非跑步低冲击）→ 2–3 周后视表现再提高摄入**；连续两周表现不回升的正确动作是 1 周 diet break，不是继续加有氧。「进食前做」降级为纯依从性选项（4 周 RCT 结局无差异）。

**修正后可用的 agent 话术**：「训练重量在掉，说明缺口或恢复债已经超标——这时候绝对不能再降热量。但先别急着改，3 周体重不动的量级跟正常波动差不多，先确认是不是真平台。如果真平台，我们把新增的缺口交给有氧而不是饮食——文献里来自运动的缺口更能保住肌肉和力量；表现还不回升再考虑加一点摄入。」

## P08 — 条件化回答 + 经验/理论分层

**案例**：「我想增肌又想减脂，能同时进行吗？75 公斤，体脂 22% 左右，练了半年。」

**Ruihan 的回答**：要看肌肉量。肌肉量比较少的话，是可以做到增肌减脂同时的。增肌本质是肌肉撕裂后的修复；新手因为动作不稳定、肌群不稳定，很多时候用不了太大重量，当姿势足够稳定后提高重量压迫肌肉，这时候就算有热量缺口，只要蛋白质摄入足够也能起到增肌效果，同时热量差消耗更多脂肪。**（作者注：这是我个人经历——一开始动作不稳上不去重量，稳定之后即使有热量差也完成了增肌减脂同时进行。不过这是我的体验，我不能确保理论正确。）**

**模式拆解**：
- **不给 yes/no，给条件**：「要看肌肉量」——同一问题对不同现状的人答案不同（同 P04 的信息优先，但这里条件本身就是答案的一部分）
- **给机制而非结论**：解释为什么新手可以（刺激潜力未兑现 + 蛋白充足 + 缺口供能），让用户理解适用条件而不是记住一个"能/不能"
- **经验/理论分层**（关键）：明确标注这是个人经历，不保证理论正确——**教练分享经验时，听者极易当作普适真理**

**抽象模式**：现状决定答案时给条件不给结论；讲机制让用户理解适用边界；**个人经验必须标注为经验**。

**知识状态**：✅ 已裁决（`body-recomposition-2026-08-16.md`，49 条引用核验）。**「做对了但原因说错了」**——

- **结论层成立**（且门槛比作者说的宽：有训练者也能 recomp），案例（75kg/22%/半年）判定成立。但判据不是"肌肉量"，是三个可测变量：**训练年限/适应潜力、起始体脂、缺口大小**
- **机制层修正**：①「撕裂—修复」被 Damas 2016/2018 直接否定，主机制是**机械张力**；②「技术不稳→用不了大重量→刺激不足」因果错置——新手负荷数字含大量技能成分，但负荷 40% 1RM 以上接近力竭时肥大与负荷高低无关，新手恰恰是肥大最快人群；③「蛋白够就行」半对——需**三条件并列**：刺激推进 + 蛋白 ≥2 g/kg + 缺口 ≤500 kcal/日
- **修正后 agent 话术**：「你现在训练时间不长、体脂也不算低，增肌和减脂是可以同时的，文献里这个条件的人很多都做到了。关键不是练到酸疼，是把训练稳定做上去、蛋白吃够、别把热量砍太狠——缺口太大时蛋白只能保肌肉不能长肌肉。」

## 元模式（跨案例的通用规则）

**M01 — 教练标注自己的不确定，不假装确定。** Ruihan 在 P06 主动标注「这里知识存疑，你可以调查一下」，在 G01 直接说「这个我给不了建议，我没遇到过」。这与产品的证据纪律同构：**不确定就说不确定，然后去查**——权威来自诚实与可核查，不来自笃定的语气。agent 遇到知识包未覆盖的问题时应同样处理（现有分级拒答机制已实现：领域内标注"未经验证的一般知识"、数值类拒答）。

**M02 — 经验主张与普适主张必须分层。** Ruihan 在 P08 明确区分「我这样做成了」与「理论上就该这样」。agent 的表述纪律：
- 来自知识包已审证据 → 陈述为一般性结论，带证据分级与适用人群
- 来自教练经验语料 → 表述为「有经验的做法是…」，不冒充普适真理
- 用户自身历史 → 表述为「你上次…」，是最强的个体证据但不外推给他人
三者不得混为一谈。这条与 evidenceStatus 分级、Expected muscle association 的免责声明是同一纪律在话术层的延伸。
