# 有氧、抗阻并行训练与低血糖边界：给 MaxPower Planner 的可执行依据

> 调研日期：2026-08-12
> 适用范围：无禁忌、能自主运动的健康成人。本文不是对糖尿病、反复低血糖、心血管疾病或伤病的医疗处方。

## 结论先行

有氧不是“减脂附属动作”，而是需要同力量训练、恢复、日程和能量摄入共同排程的一类训练。对以减脂且保持/发展体型为主的人，默认顺序应是：**力量训练优先；有氧作为可逐步增加的独立剂量；同一节只能合并时，先力量、后低至中等强度有氧。**

“空腹有氧燃脂更好”不应成为产品承诺。空腹会改变运动当时使用的底物，但在能量限制、训练量匹配的随机试验中，没有带来更多体脂或体重下降。它只可作为安全筛查通过后的个人偏好/日程选项。

对糖尿病、使用胰岛素或促胰岛素分泌药、反复/已证实低血糖、晕厥或不明运动中症状的人，Planner 不得自动安排空腹有氧或 HIIT；必须要求既有临床运动方案、监测方式和低血糖处理方案，并以暂停/求助而非“吃多少碳水”作为自动化边界。

## 证据与不能做的推断

| 结论 | 证据 | 产品不能声称什么 |
| --- | --- | --- |
| 空腹有氧会改变急性脂肪/碳水底物利用。 | 空腹/进食状态的系统综述与荟萃分析，[Vieira 等 2016](https://pubmed.ncbi.nlm.nih.gov/27609363/)（A）。 | 运动当下更多脂肪氧化 = 长期更多体脂减少。 |
| 在低热量饮食下、训练量相同的 4 周 RCT 中，空腹与进食后 LISS 都减重/减脂，组间无体组成差异。 | [Schoenfeld 等 2014](https://pubmed.ncbi.nlm.nih.gov/25429252/)（A；样本小、年轻女性、4 周）。 | 已证明任何人空腹有氧更有效，或空腹是减脂必要条件。 |
| 并行训练可用于降低脂肪量；训练量与持续时间重要，同日和异日并行在体脂百分比结果上无显著差异。 | [2025 系统综述/荟萃分析](https://pubmed.ncbi.nlm.nih.gov/40405489/)（A）。 | 有氧必然“干扰增肌”，或只要拆天就一定更好。 |
| 若力量/体型优先且必须同一节，抗阻→耐力对下肢动态力量优于耐力→抗阻；体脂百分比与增肌未见顺序优势。 | [Eddens 等 2018](https://pubmed.ncbi.nlm.nih.gov/28917030/)（A）。 | 同节先有氧必然无效；这是一条不允许偏离的规则。 |
| 并行时爆发力的削弱在同一节较明显；相隔至少 3 小时的研究子组未见该削弱。 | [Schumann 等 2022](https://pubmed.ncbi.nlm.nih.gov/34757594/)（A）。 | “至少 3/6 小时”对所有结果与所有人都是精确恢复阈值。 |
| 较高冲击的跑步在肌纤维层面可能比骑车更不利于并行训练；整体肌肉肥大结果未见明确损害。 | [Petré 等 2022](https://pubmed.ncbi.nlm.nih.gov/35476184/)（A）。 | 跑步在减脂期必须禁止；应依据关节耐受、偏好、腿部训练反应和总量选择。 |
| 健康收益的通用起点是每周 ≥150 分钟中等强度或 ≥75 分钟高强度（或组合）；体重长期维持常需逐步达到 200–300 分钟中等强度。 | [ACSM 2011](https://pubmed.ncbi.nlm.nih.gov/21694556/)；[ACSM 2009](https://pubmed.ncbi.nlm.nih.gov/19127177/)（A）。 | 初学或减脂者第一周就应达到 200–300 分钟。 |

## 教练式决策，而不是固定模板

### 1. 先决定有氧在这一个周期的角色

Planner 必须收集并持久化 `cardioPurpose`，而不是只问“要不要有氧”：

- `health_base`：健康、日常活动、心肺基础；
- `fat_loss_activity`：在饮食计划之外增加可持续活动消耗；
- `endurance_performance`：跑步/骑行/球类等耐力表现优先；
- `recovery_mobility`：主观轻松的活动恢复；
- `preference_enjoyment`：因喜欢、通勤、社交而做。

同样的 30 分钟快走，在这几种目标下的排程优先级、是否应该推进、是否可与腿日合并都不同。减脂也不能把所有赤字交给有氧：系统应同时追踪实际摄入、步数/日常活动、已完成训练和体重/腰围趋势。

### 2. 用可解释强度，而不是“燃脂区”神话

首选用户可理解的 `talk test + RPE`；有可用且可信的心率历史时再显示心率区间，不能仅用预测最大心率做精确承诺。

| 层级 | 可写入计划的说明 | 默认用途 | 对恢复账本的含义 |
| --- | --- | --- | --- |
| 轻松 / LISS | RPE 2–4；可完整交谈；如快走、轻松单车、低阻椭圆机。 | 起步、力量后补充、恢复日、增加日常活动。 | 低疲劳，不应自动阻塞下次力量课；仍记录时长、模式与腿部主观反应。 |
| 中等连续 | RPE 4–6；可短句交谈但不能长谈。 | 健康与逐步增加周剂量。 | 对下肢/整体疲劳有中等影响；紧邻重腿日时优先低冲击、缩短或改日。 |
| 高强度间歇 / HIIT | 高努力、间歇结构，必须明确恢复段和总工作量。 | 已有基础、明确偏好或耐力目标；不是减脂默认开关。 | 高疲劳事件；与重下肢、跑跳、硬拉等共享恢复约束，需用实际 RPE、完成度与下肢状态复核。 |

强度只能是处方起点。每次完成后须记录：`mode`、工作/总分钟、RPE、是否完成、是否出现头晕/异常不适、下肢疲劳和可选心率/配速。没有这些，Planner 不得把估算消耗当作真实赤字。

### 3. 安排时间：先保留优先适应，再选择低摩擦方案

1. **体型/力量优先、同一节不得不合并**：先完成力量，再加 LISS 或短中等有氧；有氧时长由当日剩余时间与恢复预算决定。这样不是因为“训练后燃脂更神奇”，而是保护力量训练的质量；综述对下肢动态力量支持此顺序。[Eddens 等 2018](https://pubmed.ncbi.nlm.nih.gov/28917030/)
2. **耐力表现是主目标**：可先做耐力关键课，或拆为不同日；UI 必须明确这是在为耐力质量让位，不得仍把“体型优先”标为默认。
3. **高强度间歇、冲刺、长距离跑与重下肢日**：优先分开日；同日必须安排时，应与高质量力量相隔至少约 3 小时作为**降低潜在干扰的偏好规则**，并以个人表现/恢复验证，不标成医疗或生理阈值。[Schumann 等 2022](https://pubmed.ncbi.nlm.nih.gov/34757594/)
4. **非训练日**：LISS/中等连续有氧可以放入，但应先检查连续日程、腿部残余负荷、睡眠和疲劳；它不是“休息日必须补偿消耗”。
5. **空腹**：仅当用户主动选择、没有安全屏障、强度低至中等且当日没有需要高质量完成的力量/间歇任务时给出；显示“与进食状态相比无已证实的额外长期减脂优势”。任何出现发抖、出汗、眩晕、意识模糊等不适应立即停止，而非让算法继续加量。

## 与已实现的肌群疲劳模型如何组合

当前动作恢复表可继续作为力量课程的局部肌群负荷来源；有氧要新增一个**独立但可汇总**的 `cardioLoad`，而不是把跑步粗暴记成“腿训练组数”。

```text
实际有氧记录（模式、时长、RPE、坡度/间歇、完成度、症状）
  → cardioLoad：系统负荷 + 下肢局部负荷 + 冲击等级 + 心肺刺激
  → 与力量动作的肌群疲劳预测合并
  → 候选下一节课评分：力量质量 / 局部恢复 / 系统恢复 / 用户可用时间
  → 排：力量、力量后低冲击有氧、单独有氧、轻活动恢复、或休息
```

建议数据结构（产品规则，非生理测量）：

```ts
type CardioPrescription = {
  purpose: "health_base" | "fat_loss_activity" | "endurance_performance" | "recovery_mobility" | "preference_enjoyment";
  modality: "walk" | "incline_walk" | "bike" | "elliptical" | "rower" | "run" | "intervals";
  intensityBand: "easy" | "moderate" | "vigorous_intervals";
  minutes: number;
  placement: "after_resistance" | "separate_session" | "non_resistance_day";
  earliestStartAfter?: string;
  rationale: string[];
  safetyStatus: "eligible" | "needs_clinician_plan" | "hold_for_symptoms";
};

type CardioCompletion = {
  actualMinutes: number;
  sessionRpe: number;
  modality: string;
  completed: boolean;
  symptoms?: ("dizzy" | "shaky" | "confused" | "chest_pain" | "unusual_breathlessness")[];
  glucoseContext?: "not_applicable" | "self_monitored_per_clinician_plan";
};
```

### 可测试的 Planner 规则

这些是从上列证据转化而来的版本化产品规则，须保存规则版本、理由与覆盖条件：

1. **初始剂量**：若近期有氧记录缺失，先给每周 2 次、每次 20–30 分钟 `easy` 低冲击选项，或等量可拆分的步行；不是直接开 HIIT，也不伪造 kcal 消耗。
2. **渐进资格**：只有当最近 7–14 天计划完成度、力量可比表现、睡眠/疲劳及下肢恢复没有负面趋势时，才每次增加一个小剂量变量（单次时长、一次额外 easy session 或强度），不可同周同时增加力量量、HIIT 和有氧分钟。
3. **同日放置**：`physique/strength priority + same session` → `after_resistance + easy/moderate + lower-impact preference`。若当日为高疲劳下肢或硬拉，默认删减/改为步行，或转移到另一天；只在用户复核后保留间歇。
4. **连续队列**：有氧是一个候选任务，不消耗胸背肩腿训练队列。它可填补恢复允许、日程可用的窗口，但不能因为“有氧已做”就当作完成了一节抗阻课。
5. **空腹呈现**：只给“可选偏好”开关；文案：`空腹可能改变当时的能量来源，但在相同饮食和训练量下没有可靠的额外长期减脂优势。选择你能安全、稳定完成的时间。` 默认关闭。
6. **HIIT 门槛**：需有近期 easy/moderate 完成史、无安全屏障、用户明确愿意、且该周下肢/系统恢复允许；否则只提议低冲击 easy/moderate。
7. **反馈触发**：连续未完成、下肢酸痛/疲劳升高、力量可比表现下降，或症状出现 → 暂不递增，生成“缩短、改低冲击、改日或恢复活动”的可确认提案。异常症状优先进入安全流程。

## 低血糖、糖尿病与症状：不可越界的安全流程

ADA 指出，运动的血糖反应会随运动类型、时机和治疗而变；使用胰岛素或促胰岛素分泌药者通常需要结合碳水与/或药物调整、频繁监测来降低低血糖风险。[ADA 运动立场声明](https://diabetesjournals.org/care/article/39/11/2065/37249/Physical-Activity-Exercise-and-Diabetes-A-Position)（A）。这不授权 Planner 开药、调药或把一张通用加餐表伪装成个体医疗方案。

### 必填安全筛查，而非猜测“低血糖”

- 是否诊断糖尿病；类型（如愿意提供）；
- 是否使用胰岛素或会导致低血糖的促泌剂；
- 是否有反复/已测得低血糖、晕厥，或运动中的发抖、出汗、头晕、意识混乱；
- 是否已有医生/糖尿病教育者提供的运动、监测和低血糖处理方案；
- 是否能在按该方案训练时使用血糖仪/CGM及携带既有处理用品。

### Planner 输出状态

| 发现 | 自动化行为 |
| --- | --- |
| 胰岛素/促泌剂、已确诊反复低血糖，或无明确管理方案 | `needs_clinician_plan`：不自动排空腹/HIIT；请求录入临床团队已给的运动方案和监测约束。 |
| 当下或运动中出现低血糖/晕厥/意识改变相关症状 | `hold_for_symptoms`：停止该训练建议，提示按既有紧急处理方案处理并寻求及时专业帮助；不继续计算燃脂、消耗或进阶。 |
| 用户仅自称“低血糖”、没有诊断或可验证记录 | 不诊断；收集症状/时机/既往评估，避免自动空腹与高强度处方，并建议向合格临床人员确认。 |
| 无上述风险，选择空腹 LISS | `eligible` 但提示补水、低强度、停止信号；完成后记录耐受性。 |

ADA 给出的特定碳水与血糖数字必须在其适用的糖尿病治疗和监测语境中使用；产品可链接给用户和临床团队讨论，但不应自行替代为“所有人晨练前吃 X 克”。[ADA 2026 标准](https://diabetesjournals.org/care/article/49/Supplement_1/S89/163932/5-Facilitating-Positive-Health-Behaviors-and-Well)（A）。

## 客户端应如何解释，而非掩盖不确定性

示例卡片：

> **今天力量后：斜坡走 20 分钟，轻松强度（RPE 2–4）**
> 原因：你本周期优先保持力量质量；低冲击有氧能增加活动量，同时比训练前有氧更少占用今天的力量表现。它不是“训练后燃脂魔法”。若腿部疲劳、睡眠差或无法完整交谈，可缩短为 10 分钟步行或跳过，并记录原因。

示例空腹卡片：

> **空腹有氧是时间偏好，不是加速减脂方式。**
> 在相同摄入和训练量下，目前没有可靠证据显示它比进食后有氧带来更多长期体脂下降。若出现头晕、发抖、异常出汗或意识不清，请停止；若有糖尿病、低血糖史或相关用药，请遵循临床团队的运动方案，Planner 不会自动安排空腹训练。

## 实施优先级与验收

## 四象限：哪些由证据决定，哪些必须向用户学习

教练课程的价值不是把所有未知都写成固定公式。对每一个有氧决策，Planner 应把知识来源分开，且只向用户索取会实际改变下一步处方的少量信息。

| 象限 | 内容 | Planner 的责任 | 例子 |
| --- | --- | --- | --- |
| 1. 双方都知道 | 高信号、可普适的证据与安全边界。 | 作为透明默认值和约束，而非个体承诺。 | 同节且体型/力量优先时先力量后有氧；空腹不承诺更多长期减脂；胰岛素/促泌剂与低血糖风险不自动排空腹/HIIT。 |
| 2. 用户知道、系统不知道 | 生活约束、既往反应、偏好与临床既有方案。 | 只问最多 3 个会改变首周排程的问题；其余由实际记录慢慢获得。 | (a) 有氧首选/最讨厌的方式与可用时段；(b) 腿日后跑步、单车或坡走的真实恢复/膝踝耐受；(c) 糖尿病/相关用药、低血糖或晕厥史及已有临床运动方案。 |
| 3. 用户不知道、系统知道 | 把训练科学和已记录事实转译成可执行、可覆写的候选方案。 | 给出理由、强度、停止/调整条件和不确定性。 | 将“想加速减脂”转换为先从低冲击 easy 2×20–30 分钟开始；解释训练后安排的目的在于保护力量质量，而非承诺额外燃脂。 |
| 4. 双方都不知道 | 个体在某种模式/剂量/时机下的真实表现、恢复和依从性。 | 设计低风险、可撤销的 N-of-1 小实验；不臆测答案。 | 同样 20 分钟、同样周总量下，比较力量后斜坡走和非力量日快走对完成度、下肢疲劳、睡眠、下一次腿部表现和体重/腰围趋势的影响。 |

### 首次只问这三项

1. **可持续性**：`你一周实际能稳定留给有氧的时段/总分钟是多少？最愿意做哪两种方式？` 这决定方式和起始剂量。
2. **恢复与耐受**：`重腿/硬拉后的 24–48 小时，跑步、单车、坡走或椭圆机中，哪一种最影响或最不影响腿部/背部恢复？有膝、踝、腰疼或不适吗？` 这决定冲击等级与同日/分日。
3. **安全屏障**：`是否有糖尿病、胰岛素/促泌剂、反复低血糖/晕厥或运动中异常症状？若有，临床团队给了什么运动与监测方案？` 这决定是否禁用自动空腹/HIIT。

身高、体重、目标、可用训练日、近期训练与恢复 check-in 已存在时，不应再重复询问。用户可以跳过第 1、2 项；系统随即采用保守、低冲击、非空腹、低剂量默认，并明确这会降低个体化置信度。第 3 项若存在风险信号则不能跳过安全流程。

### 不知道时的最小 N-of-1 实验协议

不把个人体验直接推广成普遍规律。一次只改变一个变量，且不在强赤字、睡眠显著变差、训练队列正在调整时同时变更力量量与有氧量。

```text
前提：无安全屏障；近 7 天力量安排和摄入策略稳定
方案 A（1–2 周）：2 × 20 分钟，力量后低冲击 easy（RPE 2–4）
方案 B（1–2 周）：同方式、同总分钟，非力量日或与力量相隔 >=3h
固定：周总有氧分钟、力量计划、摄入目标尽可能一致
记录：完成率、session-RPE、腿/背疲劳、睡眠、下一次可比力量表现、7 日体重均值/腰围
判定：优先选完成率高、恢复/表现不变差且能长期维持的方案；若无清晰差异，以日程偏好为准
```

空腹只能作为另一个独立实验变量，且只在安全筛查通过、低强度、非关键力量日前提下比较；固定总热量与有氧剂量，观察耐受性和依从性，而不将单次“出汗更多/心率更高”解释为更多减脂。

**P0（先于任何“智能配有氧”）**

1. 结构化安全筛查与 `CardioPrescription/Completion` 持久化；症状/用药屏障覆盖空腹和 HIIT。
2. 计划—实际有氧负荷账本，纳入连续恢复队列和每日能量预算的“不确定估计”字段。
3. 有氧目的、强度、模式、放置位置、理由、停止/调整条件在客户端可见且可覆写。

**P1**

1. 低冲击优先、下肢日/硬拉日与间歇冲突的动作级排程。
2. 7–14 天趋势门控的渐进；把实际体重/腰围/摄入/步数用于校准，而不是按计划分钟承诺体脂变化。

**最低验收场景**

- 体型优先、同节训练：力量课先于 20 分钟 easy 单车/斜坡走，并带理由；
- 重腿/硬拉后：次日不自动塞跑步 HIIT，候选改为低冲击、改日或恢复活动；
- 耐力优先：解释为什么耐力关键课排在力量前/另一日；
- 空腹开关：不能提高预估脂肪减少，不通过安全筛查则不可选；
- 胰岛素/促泌剂或低血糖/晕厥信号：不产生自动空腹/HIIT处方；
- 有氧完成度低、RPE/疲劳上升或力量表现下降：下一周期不递增，而给可确认的调整方案。
