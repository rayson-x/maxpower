# 市场调研：简单训练动作跟练 App

_调研日期：2026-08-05。范围：当前仍有官方网页或官方应用商店页的手机/平板训练产品；优先核查官网、官方帮助中心和 App Store / Google Play 页面。本文中的“跟练”指 App 按既定顺序展示动作，并用视频、动画、语音或计时推动用户完成一节训练。厂商没有明确说明的摄像头识别、计数或动作纠错能力，一律不作推断。_

## 结论

**有，而且已经是成熟、拥挤的市场。** 简单跟练并不是稀缺能力，代表产品从“7 分钟动画 + 倒计时”到“教练视频课程 + 训练计划”都有：

- **最接近极简跟练**：Seven、Leap Home Workout。用户选择时长或身体部位后即可开始，界面围绕当前动作、计时和下一个动作展开。
- **内容型跟练**：Keep、Nike Training Club、FitOn、Apple Fitness+。核心是教练视频、课程筛选与内容库，体验成熟，但选择和内容层级更多。
- **计划型跟练**：Freeletics、Sworkit。先根据目标、时间、器材等组织训练，再逐项带用户完成；“AI”主要用于计划个性化，不等于摄像头实时看动作。
- **摄像头反馈型**：Kemtai 等产品公开提供视觉测量与实时反馈，但更偏 B2B/康复或集成方案，不是上述大众 App 的默认能力。

因此，对 MaxPower 更有价值的切口不是再做一个课程库，而是采用极简跟练的交互，同时把已有的**动作身份、计数、观察质量和拒答原因**变成真实闭环。第一版不应把“动作标准分”或泛化 AI 私教作为核心承诺。

## 本文如何区分产品

| 层级 | 用户实际得到什么 | 是否知道用户真的做了 |
| --- | --- | --- |
| 视频课程 | 跟着真人教练的同一时间线做 | 通常不知道 |
| 动作卡片/动画 | 当前动作演示、倒计时、休息、语音提示 | 通常不知道，完成由用户确认或按时间推进 |
| 个性化计划 | 根据目标、器材、时间或用户反馈编排动作 | “计划适配”不等于“动作识别” |
| 传感器指标 | 手表/心率带提供心率、热量、时长等 | 知道生理或活动指标，不等于知道动作姿势 |
| 摄像头识别 | 根据画面计数、测量或给反馈 | 可以知道部分可观测动作，但受机位和遮挡限制 |

## 市场结构

```text
极简动作序列
  Seven / Leap Home Workout
  优点：打开快、认知负担低
  缺口：不知道用户是否真的完成

教练内容平台
  Keep / Nike Training Club / FitOn / Apple Fitness+
  优点：示范、节奏、陪伴和内容质量成熟
  缺口：内容选择多，通常不看用户动作

个性化计划
  Freeletics / Sworkit
  优点：能适配目标、时间和器材
  缺口：计划个性化常被误解成动作识别

视觉测量/反馈
  Kemtai 等 B2B 方案，另有 Tempo/Tonal 等硬件闭环
  优点：能形成计数或反馈闭环
  缺口：机位、遮挡、动作 profile、硬件或集成成本
```

## 对 MaxPower 的建议

### 1. 做“极简跟练壳 + 可解释识别”，不要先做课程平台

最小训练流程可以只有：

1. 选择一个已支持的动作与器材；
2. 用简短循环演示和文字提示摆好相机；
3. 显示当前动作、目标次数/时间和开始按钮；
4. 训练中只展示可靠的次数、阶段和一句 cue；
5. 看不清时明确提示缺失点、机位或遮挡，不生成分数；
6. 结束后用一页复盘说明正式次数、待审核次数和观察发现。

这套体验借鉴 Seven/Leap 的低信息密度和 NTC Whiteboard 的健身房适配，但把 MaxPower 已有的 canonical packet、confirmed/needs-review/rejected 与 observation findings 变成真正差异。

### 2. 第一版优先“单动作/单组跟练”

不要一开始就做多周计划、社区、饮食、直播或数百动作库。更可验证的 MVP 是：用户选一个动作，App 展示 2–4 秒循环演示，用户做一组，系统给出计数和可解释观察。动作 profile 不支持时不允许伪装成通用识别。

### 3. 把三种提示在界面上分清

- **预先教学**：所有用户都会看到的动作要点；来自内容，不是观察结果。
- **实时观测**：如“已完成 5 次”“速度偏快”；必须来自当前 canonical packet。
- **无法判断**：如全身未入画、关键点缺失、机位不匹配；这是产品能力，不是失败页面。

### 4. 不用“AI 教练”作为能力简称

竞品中的 AI 可能只是计划推荐、聊天或训练后自评适配。MaxPower 应直接写清“摄像头计数”“观测到的 2D 指标”“未经校准不评价标准度”，这样比一个含义模糊的 AI 标签更可信。

## 推荐的首轮原型对标

| 要验证的问题 | 建议参考 |
| --- | --- |
| 用户能否在 10 秒内开始一组 | Seven / Leap Home Workout |
| 健身房里如何少看屏幕完成序列 | NTC Whiteboard workout |
| 如何展示真人动作与节奏 | Keep / FitOn / Apple Fitness+ |
| 如何收集训练后的主观难度 | Freeletics |
| 如何把摄像头能力说清楚 | Kemtai 的测量型定位，但采用本项目更严格的拒答和证据合同 |

## 不应从本次资料推出的结论

- 官方写“AI Coach”“实时指导”或“纠正动作”不代表使用摄像头实时分析。
- App Store 的评分、下载量和厂商宣称不能独立证明训练效果、动作安全性或识别精度。
- 有心率、热量或 Apple Watch 指标不代表系统知道用户做的是哪一个动作。
- Kemtai 等厂商公开的动作数量不能证明每个动作、机位、器材和人群都有相同可靠性。
- “简单跟练”验证了用户交互需求，不等于已经验证 MaxPower 的视觉测量质量。

## 调研限制

- 应用功能、地区可用性和订阅价格会变化；采购、设计冻结或竞品拆解前应再次打开对应地区商店核验。
- 本次以公开一手资料为准，没有创建所有产品的付费账户逐屏体验，因此“简洁程度”是基于官方展示的产品流程判断，不是可用性实验结果。
- 中国市场中存在多个同名或近似名的 FitTime/FITtime 产品，公开一手资料难以稳定对应到历史上的中文健身跟练品牌，本表没有将它作为已核实的当前代表产品。
- 本文不评价具体训练方案是否适合个体，也不作医疗、安全或损伤风险判断。
