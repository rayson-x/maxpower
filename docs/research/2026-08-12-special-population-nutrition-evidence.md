# 特殊人群营养摄入一手证据：可吃 / 不可吃 / 进食范围提醒

> **目的**：MaxPower 第一版只做热量估算，但用户明确要求对特殊人群做「进食范围提醒」（可吃 / 不可吃）。本文为客户端 agent 提供可核验的一手证据条目，面向**普通用户**，语气清晰、支持性、不恐吓。
> **定位**：我们的角色是「进食范围提醒」，**不是**饮食治疗处方。疾病相关营养建议一律是「配合医嘱」，不是替代医嘱。每一条都写明「转介边界」——什么情况必须咨询医生或注册营养师。
> **纪律**：只收临床指南 / 立场声明 / 科学建议（ADA、AHA/ACC、KDIGO、KDOQI、ACOG、CDC/FDA、USPSTF、ACR、ESPEN、NOF/IOF、DASH 等）与系统综述 / Meta 分析；不用博客与媒体转述；每条写明「不能推出什么」防止过度声称。所有 PMID 已通过 NCBI E-utilities 逐条核验（题名、期刊、年份一致）；核验未过或无法定位的标「待核验」。
> **证据等级**：A = 临床指南 / 立场声明 / 系统综述 / Meta 分析 / RCT。本文只收 A 级条目；证据不足的方向注明「不收录」。

## 使用约定

- 每个主题结尾的固定话术：**「这些是通用提醒，你的具体情况请遵医嘱。」**——客户端 agent 在输出该人群提醒时必须携带。
- 「可吃」不等于「多吃就好」，「避免」不等于「碰一口就危险」；提醒要给出方向与量级，不给绝对化表述。
- 慢性肾病、用药人群的条目默认只在用户主动声明病情/用药后触发，不做病情推断。
