# 健身流派对账：网红理论 vs 论文证据

> **目的**：让 planner 的每一条安排都能说出"为什么这么排"，并且指得出证据。
> **方法**：先列社交媒体广泛流传的说法，再对同一问题查一手文献/系统综述，最后给我们的产品立场。
> **纪律**：每条标注证据等级；标为「待核验」的不得进知识包。

---

## 0. 怎么读这份文档

每条按同一结构：**流传说法 → 证据 → 我们的立场（含前因后果链）**。

前因后果链的统一格式：

```
目标 → 生理机制 → 可操作变量 → 计划里的输出 → 验证指标 → 证据锚点
```

# Part A · 减脂维度

## A1. 点减脂（练哪瘦哪）

**流传说法**：练腹肌减肚子、练手臂瘦手臂、"腰细要多练侧腹"。

**证据**：
- 13 项高质量单侧训练研究、共 1158 人：**训练侧与未训练侧的脂肪减少无实质差异**
- [系统综述与 Meta（含提出检验模型）](https://hummov.awf.wroc.pl/A-proposed-model-to-test-the-hypothesis-of-exercise-induced-localized-fat-reduction,143162,0,2.html)：可以增大局部**肌肉**，但不能显著减少该部位**脂肪**
- **争议点（诚实标注）**：[2023 一项 RCT](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC10680576/) 报告腹部耐力运动组躯干脂肪减少更多。这是单一未被重复的研究，对照的是 123 项试验的整体结论

**我们的立场**：
```
目标：局部形态（腰细、臀翘、肩宽）
机制：脂肪分布由整体脂肪量 + 遗传分布决定；肌肉形态由局部训练决定
可操作变量：整体赤字（减脂肪）+ 局部肌肉侧重（改形态）
计划输出：不承诺点减脂；"腰细"归到整体减脂；"臀/肩明显"归到局部 emphasis 周量
验证指标：腰围（整体减脂）+ 目标肌群周量达标（形态）
证据锚点：上述 meta；争议 RCT 单独标注
```

## A2. 间歇性断食（IF / 16:8 / 5:2）

**流传说法**：断食提高代谢、激活生长激素与自噬 → 减脂更快。

**证据**：
- [Intermittent vs continuous energy restriction — 系统综述与 Meta](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC6304782/)：间歇与连续限制在减重与代谢改善上**效果相当**
- [2011-2021 更新 Meta](https://pmc.ncbi.nlm.nih.gov/articles/PMC9579470/)：几乎全部研究组间差异不显著
- [≥6 个月试验的 Meta](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC4924195/)：同方向

**我们的立场**：IF 是**进食窗口偏好**（依从性工具），不承诺额外减脂。对"三餐难安排"的用户是有价值的选项；对训练日供能不利时不推荐（见 A6 按需供能）。

## A3. HIIT vs 中低强度有氧（MICT/LISS）

**流传说法**：HIIT 的 EPOC 让你"燃脂 24 小时"，所以效率碾压慢跑。

**证据**：
- [HIIT vs MICT 对脂肪减少与心肺适能的系统综述与 Meta](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC10048683/)：HIIT 在腰围、体脂率、VO₂peak 上有显著益处，但**实践意义有限**
- 多项 Meta：两者对**身体成分改善相当**；HIIT 在**心肺适能**上更优
- **HIIT 可省约 40% 时间**达到相似的体脂与腰围变化 → 这是它的真实卖点
- 直接比较 HIIT vs MICT 的最大脂肪氧化变化：**无差异**（[Meta](https://www.sciencedirect.com/science/article/pii/S1728869X23000424)）
- EPOC 使 HIIT 显著更优这一说法，在这些 Meta 里**没有得到支持**

**我们的立场**：
```
目标：在有限时间内补足消耗缺口
机制：HIIT 与 MICT 的体成分效果相当；HIIT 时间效率更高但恢复成本更高
可操作变量：有氧形式 × 强度 × 频率
计划输出：HIIT 作为时间效率工具，≤1-2 次/周，且不与腿日相邻（干扰）；
        主体用中低强度（低干扰、易堆量）
验证指标：周有氧分钟数、力量训练负荷是否被拖累
证据锚点：上述 Meta
```

## A4. 低碳 / 生酮 / 碳循环

**流传说法**：降碳→胰岛素低→脂肪出仓；碳循环骗过代谢。

**证据**（见姊妹文档 `2026-08-11-fat-oxidation-physiology-and-fasted-cardio.md` 详述）：
- [Hall & Guo，20 项受控喂养研究](https://www.stephanguyenet.com/meta-analysis-impact-of-carbohydrate-vs-fat-calories-on-energy-expenditure-and-body-fatness/)：等热量等蛋白下体脂影响相似，**略偏向高碳**（每天约 16 g）
- [Hall et al., Cell Metabolism 代谢病房](https://www.sciencedirect.com/science/article/pii/S1550413115003502)：等热量下限制脂肪比限制碳水掉更多体脂
- [Hall & Guo 能量消耗 Meta](https://www.nature.com/articles/s41366-019-0456-3)：碳水/脂肪比例对总能量消耗无实质影响
- 碳循环：未找到超越等热量的独立证据。其**真实价值**可能在训练日供能——即 A6 的按需供能

**我们的立场**：不推荐用低碳作为减脂手段；碳水**时序**按按需供能框架安排（训练周围优先），并明确"这是为训练质量，不是为多减脂"。

## A5. 代谢适应 / diet break / refeed

**流传说法**：节食久了"代谢损伤"、refeed 能"重启代谢"。

**证据**：
- [MATADOR 试验](https://www.abom.org/wp-content/uploads/2018/10/Intermittent-energy-restriction-improves-weight-loss-efficiency-in-obese-men_the-MATADOR-study.pdf)：51 名肥胖男性、30 周，**2 周赤字 + 2 周维持交替** vs 连续赤字 → 间歇组**减重更多、代谢适应更少**
- 机制：2 周能量平衡期作为"代谢休息期"，减轻静息能量消耗的补偿性下降
- **但**："diet break 重启代谢"的说法夸大。证据支持的是：每 4-12 周赤字插入 1-2 周维持期，收益是减轻适应性产热 + 改善依从性 + 可能的瘦体重收益

**我们的立场**：
```
目标：让赤字能长期维持
机制：持续赤字引发适应性产热与 NEAT 下降；周期性维持期可减轻
可操作变量：赤字/维持的时间结构
计划输出：diet break 作为结构化工具（每 4-12 周赤字 → 1-2 周维持），
        用"计划内的维持期"措辞，绝不用"重启代谢"
验证指标：体重趋势斜率、步数趋势、恢复与饥饿评分
证据锚点：MATADOR
```

## A6. 空腹有氧 / 按需供能

见姊妹文档。**结论**：状态匹配（糖原依赖型工作放糖原足时、非依赖型放糖原低时）是正确原则，有一手框架支撑（[Impey et al., Fuel for the Work Required, Sports Medicine 2018](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC5889771/)）；但其收益是**保护高强度训练质量**，不是多烧脂肪。

# Part B · 增肌维度

## B1. 负荷范围：大重量还是小重量？

**流传说法**：两个极端都有——"必须大重量低次数"vs"高次数泵感才涨肌"。

**证据**：
- [Schoenfeld et al. 2017，21 项研究 Meta](https://pubmed.ncbi.nlm.nih.gov/28834797/)：**只要接近力竭，低负荷（≤60% 1RM）与高负荷（>60%）的肌肉增长无实质差异（效应量差 0.03）**
- **但力量增长高负荷显著更优**（1RM 提升 p = 0.003）
- 重要 caveat：1RM 测试通常在训练所用动作上进行，偏向重负荷组；用不同模态测试时该优势会减弱
- [重复次数连续谱的再检验](https://pmc.ncbi.nlm.nih.gov/articles/PMC7927075/)：同方向

**我们的立场**：
```
目标：增肌
机制：机械张力驱动肌肥大；接近力竭时较宽负荷范围可达成相似张力暴露
可操作变量：负荷 × 次数 × 距力竭距离
计划输出：增肌用较宽范围（主项 6-12、辅助 10-15），关键是接近力竭（RIR 1-3）；
        力量目标必须重负荷（≥80% 1RM 方向）
验证指标：负荷或次数是否在推进（双进阶）
证据锚点：Schoenfeld 2017 Meta；ACSM 2026
```

**这条直接解答"女性不想练太大"**：不需要用轻重量来"避免变大"——负荷范围对肌肉增长几乎等效，真正决定"大小"的是**周量与营养盈余**，不是负荷选择。想要形态而非体积，调的是**周量分配与能量平衡**。

## B2. 力竭 / 周量 / 频率

已在既有文档覆盖：力竭非必要（[Grgic 2022](https://pubmed.ncbi.nlm.nih.gov/33497853/)）；每肌群 ~≥10 组/周方向、每周 ≥2 次（[ACSM 2026](https://pubmed.ncbi.nlm.nih.gov/41843416/)）。

## B3. 蛋白时机 / 「合成窗口」

**流传说法**：练后 30 分钟必须补蛋白，否则白练。

**证据现状**：方向性共识是**每日总量与分配 > 单次时机**，"30 分钟窗口"被夸大。
**标为待核验**——需一手 meta（Schoenfeld/Aragon 的时机研究）核实后才能进知识包。

# Part C · 塑形 / Recomposition

## C1. 谁能同时增肌减脂（这条直接决定我们怎么对不同人群出方案）

**证据**（[Barakat et al. 2020, NSCA Strength & Conditioning Journal](https://journals.lww.com/nsca-scj/fulltext/2020/10000/body_recomposition__can_trained_individuals_build.3.aspx)）：

| 人群 | recomp 可行性 | 机制 |
|---|---|---|
| **新手** | **最容易**（前 3-6 个月） | 合成敏感性高 + 神经肌肉适应 |
| **复训者**（曾训练后中断） | 容易 | 肌肉记忆使再生长更快 |
| **高体脂者** | 可行 | 储备能量多，可在赤字下支撑肌肉蛋白合成 |
| **高级 + 低体脂** | 仍可能但**增肌速率很慢** | 需要更精细的条件 |

**我们的立场**（这就是"不同人群不同方案"的证据基础）：
```
很瘦的新手男生想增肌塑形
  → recomp 窗口最好，但因体脂低、储备少 → 小幅盈余 + 高蛋白 + 训练量渐进
  → 不做赤字（会浪费新手窗口）

很胖的男生想减脂塑形
  → recomp 高度可行（储备多）→ 赤字 + 抗阻优先 + 低冲击有氧
  → 明确告知："你这个阶段可以同时掉脂增肌"

有训练年限、刚过增肌期要刷脂
  → 高级 + 中等体脂 → 目标应是"保肌减脂"而非 recomp
  → 起步小赤字、维持负荷、避免同时加有氧与降碳

女性只想塑形不想太大
  → 保持有效抗阻剂量（负荷范围等效，见 B1）
  → 局部 emphasis（臀/肩/背）+ 整体减脂控制体积
  → 明确说明：自然训练下"意外变大"不会发生
```

## C2. 女性训练是否需要不同方案

**流传说法**：女性要练轻重量高次数、多做有氧。

**证据方向**：训练原则（渐进超负荷、周量、频率）**无性别特异性**；自然训练下女性肌肉增长速率显著低于男性。
**标为待核验**：女性在特定周量/频率上的反应差异是否存在（近年有相关综述，需核实后入库）。

**我们的立场**：不因性别降低训练剂量；性别相关的调整落在**能量需求换算**与**形态偏好（emphasis）**上，不落在训练原则上。

# Part F · 最小实验（共同未知转可验证假设）

| 假设 | 单一变量 | 成功信号 | 失败信号 | 需收集数据 |
|---|---|---|---|---|
| 局部 emphasis 能改形态而不失衡 | 目标肌群周量档位 | 目标肌群周量达上段、其余不低于维持线 | 总量失控或其他肌群跌破维持线 | 周量账本、依从率 |
| 体型状态应影响赤字幅度而非训练结构 | 仅改体重/体脂输入 | 赤字幅度与冲击等级变化，训练结构不变 | 结构也跟着变 | 计划 diff |
| 步数目标能守住赤字 | 是否给步数目标 | 体重趋势斜率维持、平台期减少 | 无差异 | 步数、体重趋势、依从率 |
| diet break 改善长期依从 | 是否插入维持期 | 12 周内依从率与趋势斜率更优 | 无差异或反弹 | 依从率、趋势、饥饿评分 |
