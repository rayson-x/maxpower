> 体系覆盖：NSCA-CPT、ACE-CPT、NASM（OPT）、中国国职（健身教练职业能力）、赛普 CPT

## 2. 共识：教练工作流（五体系结构高度一致）

```
① 咨询与评估（intake）→ ② 计划制定 → ③ 执行指导（教学）→ ④ 监测与调整 → ⑤ 阶段评审
```

**① 咨询与评估**（权重 23%，最被低估的一环）：
- 内容：健康筛查（PAR-Q 类）、目标与动机面谈、体能基线、生活方式与可用时间、**意愿与偏好**
- 教练培训把"开放式提问挖掘真实需求"列为独立技能（赛普沟通模块；ACE 的 MI）
- 国职特色：体测达标制（坐姿体前屈/俯卧撑/深蹲/引体）——评估是硬功夫

**② 计划制定**（29-31%）：目标拆解（SMART）→ 分化与频率 → 动作选择 → 急性变量（组次/强度/休息）→ 营养配合。特殊人群是独立子域。

**③ 执行指导**（36%，最大权重）：动作示范、分解讲解、教学顺序、保护手法、课中激励。**技能考核以"示范+讲解"为主**（国职实操：抽动作示范讲解 46 分）。

**④ 监测与调整**：每次课的观察与微调 + 周期性正式评估。自主调节（RPE/RIR、当日状态）是现代体系的显式内容。

**⑤ 阶段评审**：阶段目标复盘、下一阶段切换。

## 4. 对照 MaxPower 当前能力（缺口清单）

| 教练能力域 | 我们的现状 | 缺口 |
|---|---|---|
| 咨询与评估 | onboarding 六段式 + 自填禁忌清单 | ❌ 结构化筛查（PAR-Q 决策树）、体能基线电池、**意愿面谈**（分领域意愿向量已建 domain 模型，问题集未建） |
| 计划制定 | 组装器（周量/分化/时长/逐动作） | 🟡 已大幅改善；待补：意愿向量消费、自选动作位 |
| 执行指导 | realtime 计数 + 实测休息 + 主动建议 | ❌ 动作教学内容（示范要点/分解讲解/常见错误）——教练的最大权重域 |
| 监测与调整 | 双进阶/校准阶梯/周量/deload + 重排 | ✅ 已是强项（多数体系只教原则，我们已自动化） |
| 阶段评审 | mesocycle review + 预测 | 🟡 骨架在，内容薄 |
| 行为改变与沟通 | playbook v1 | ❌ TTM/MI 对话准则未注入（ticket 08 待 01 内容核验） |
| 安全边界 | 症状清单 + 拒绝清单 + 硬暂停 | ✅ 强于多数培训大纲 |

**关键洞察**：我们最强的是别人最难教的（自动化监测调整），最弱的是教练培训权重最大的两块——**执行指导（教学）**与**咨询沟通**。这正是"用起来不像教练"的原因：计划对了，但没有教学与对话。

## 5. 执行教学内容（新缺口，需建知识包）

教练培训的执行指导域包含可结构化的内容：每个动作的
- 示范要点（setup/轨迹/呼吸/节奏）
- 分解教学步骤（先学什么后学什么）
- 常见错误与纠正（对应我们的观察证据层）
- 保护与安全要点

来源路径：ACE/NSCA 动作库页面（[ACE Exercise Library](https://www.acefitness.org/resources/everyone/exercise-library/) 有逐步指导）、国职教材《社会体育指导员——健身教练》（高教社）的动作教学章节、赛普动作库。这些内容进知识包后，realtime agent 才能"教学"而不只是"计数"。
