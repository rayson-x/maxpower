# 药物与补剂一手证据库：只收立场声明 / 系统综述 / Meta / RCT

> **目的**：知识库中所有"非正常食物"（补剂、药物）条目必须能指回一手高级别证据，给客户端 agent 一个可执行的立场（推荐 / 不推荐 / 转介）。
> **纪律**：只收 ISSN/ACSM/NSCA 立场声明、系统综述、Meta 分析、RCT（药物限 III 期大型 RCT 或权威指南/监管评估）；单项小样本、机制推测、动物/体外研究一律不收。所有 PMID 已通过 NCBI E-utilities（esummary）逐条核验题名/期刊/年份。核验不过的进末尾「待核验」清单。
> **药物红线**：本文涉及的减脂药物全部是处方药。agent 的角色永远是「识别用户在用药 → 建议咨询医生 → 调整训练/营养配合」，绝不评价该不该用药、绝不给剂量指导。
> **证据等级**：A = 立场声明 / 系统综述 / Meta 分析 / RCT。本文不收录 B 级。
