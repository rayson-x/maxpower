动作库

SCREEN 01 · LIBRARY

65 个动作全量可选，按部位 + 推荐机位分组。「已校准 / 模拟」两层状态用青柠实心 vs 描边 chip 区分，一眼看出能力边界。

  • 已校准动作带青柠圆点角标 = Rust 权威计数
  • 模拟动作标注升级条件（"录满 8 次升级"）
  • 机位标签直接印在每行（正前/正后/左前45°）

机位引导

SCREEN 02 · CAMERA SETUP

选定动作后先落机位。俯视八向图复用 viewGating 的推荐数据，青柠涟漪标记推荐位，文字给距离/高度/理由。

  • 前置 = 识别（看屏幕）/ 后置 = 观察（组后报告）双模式卡
  • 入框校验 checklist，开拍后转实时检测
  • CTA 即"开始识别 · 录制"——录制默认开启

实时识别

SCREEN 03 · LIVE · DARK

深色拍摄页，青柠发光骨架是绝对主角。超大 rep 数字左下，相位 pill 顶部，REC 常驻——录制是这个 App 的一等公民，不是隐藏功能。

  • agent 便签条：一行实时观察（本地引擎输出）
  • 右侧 telemetry：FPS / 有效帧 / 模型档位
  • 入框合格横幅，不合格时变陶土橙并给方向提示

组后报告 · 抽屉

SCREEN 04 · SET REPORT

结束本组 → 底部抽屉拉起。「教练便签」是 agent 输出的人格化容器：青柠书脊 + 脉搏圆点 + "本地引擎 · 零上传"信任标。observation_findings 中文文案化成 finding 卡，rep 幅度条一目了然。

  • 每组结束自动落盘本机存储（关键点 JSON + 可选 mp4）
  • 不打分，只陈述证据
