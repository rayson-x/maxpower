# 训练编排与饮食耦合设计

> 回答六个具体问题：负荷怎么定、组数怎么定、"能做完就合适"对不对、有氧与力量怎么排、每周怎么休息、训练日/休息日怎么吃（含碳循环分布）。
> 每条给出前因后果链与证据锚点。数值标注等级：**A/B 证据** · **D 产品规则** · **待核验**。

---

## 1. 负荷怎么确认（三种信息状态，三套做法）

| 用户信息状态 | 做法 | 输出标记 |
|---|---|---|
| **有该动作的精确历史**（负荷+次数+RIR） | 按上次表现锚定，走双进阶 | `predicted_target` |
| **只有自报 1RM**（无次数/RIR 上下文） | 给**校准起点建议**（Epley 反解 × 0.9 保守折扣），首组确认后据实调整 | `unknown` + `calibrationStartSuggestion` |
| **什么都没有** | 校准阶梯：保守起点 → 按报告的 RIR 调档（最多 3 次试做） | `unknown` + `calibrationIntent` |

**为什么第二种不直接给目标负荷**：自报 1RM 缺少"在几次、什么 RIR 下测的"这个上下文，把它换算成精确工作重量是伪精确。这条是仓库既有不变量（`只有 kg、没有次数/RIR 的力量基线不能伪造精确工作重量`），本设计遵守。

**进阶规则（D，锚定 ACSM 2009）**：同一负荷下能比目标次数多完成 1-2 次时，先加次数到区间上界；连续两次达上界后加最小器材档（不超过 +10%）。

## 2. 「能用 X 重量做 X 组就是合适的重量+组数」——这个判据不完整

**核心问题**：「能做完」这句话没有包含**距力竭多远**的信息。

同一个「3 组 × 10 次 @ 40kg 能做完」可能是：

| 实际情况 | 判定 | 应该怎么做 |
|---|---|---|
| 最后一组做完还能再做 6-8 次（RIR 6-8） | **太轻**，机械张力不足 | 加重 |
| 最后一组做完还能再做 1-3 次（RIR 1-3） | **合适**（增肌工作区间） | 维持，按双进阶推进 |
| 最后一组勉强做到第 10 次（RIR 0） | 到力竭了 | 有效但恢复成本高，不必每组如此 |
| 第 3 组只做到 7 次 | **太重**（或组数过多） | 减重或减组 |

**完整判据需要三个量**：`负荷 × 次数 × 距力竭距离(RIR)`。缺任何一个都无法判断是否合适。

**所以我们的判据是**：
```
在目标次数区间内完成，且最后一组的 RIR 落在目标区间
  → 增肌工作期 RIR 1-3；校准期 RIR 4-5；力量主项 RIR 1-3 且负荷 ≥80% 1RM 方向
```

**证据**：力竭非必要（[Grgic 2022](https://pubmed.ncbi.nlm.nih.gov/33497853/)）；RIR 可作为可靠的负荷处方工具（[Lovegrove 2022](https://pubmed.ncbi.nlm.nih.gov/36135029/)）；负荷范围较宽但需接近力竭（[Schoenfeld 2017](https://pubmed.ncbi.nlm.nih.gov/28834797/)）。

## 3. 组数怎么确认（不是"感觉够了"，是周量反推）

```
① 周量目标（每肌群每周直接组数）← 目标 × 经验 × 训练意愿
   增肌：中级/高级取分档上段（~10-12 组/周方向，ACSM 2026）
   减脂保肌：维持段（~6-8 组/周）
   力量：维持段（周量非主要变量，相对负荷才是）

② 该肌群每周真实暴露次数 ← 分化轮转结构 × 每周训练天数
   注意：必须数"该肌群作为直接目标出现的 slot 次数"，
        不是轮转的名义次数（否则胸这种只在部分课出现的肌群会被除得过小）

③ 每次组数 = 周量目标 ÷ 真实暴露次数
   下限：主项 slot ≥2 组（低于此无有效刺激）
   上限：主项 ≤6 组、辅助 ≤4 组（单课单动作过量的边际收益低）

④ 首次暴露封顶（保守起点）：新手 2 组、其他 3 组
   仅作用于**第一周**与 deload 周；次周起向周量目标推进
```

**为什么首周要封顶**：没做过的动作，技术未稳定、酸痛反应未知。但这个封顶**不能永久化**——否则周量永远达不到目标（这是我们修过的真实缺陷）。

## 4. 有氧与力量怎么排（干扰管理 + 按需供能）

**两条原则**：

**原则 A（干扰）**：高强度有氧放在力量训练**前**会损害力量表现 → 力量训练的刺激变弱 → 减脂期瘦体重保不住。
**原则 B（按需供能，[Impey 2018](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC5889771/)）**：糖原依赖型工作放在糖原足的状态；不依赖糖原的工作可放在糖原低的状态。

| 排布 | 判定 | 理由 |
|---|---|---|
| 力量 → 低强度有氧（同课） | ✅ 可以 | 力量先拿到糖原；有氧不依赖糖原 |
| 低强度有氧 → 力量（同课） | ⚠️ 低强度短时可接受，但不推荐 | 会消耗一部分状态 |
| **HIIT → 力量（同课）** | ❌ **禁止** | 高强度有氧耗糖原且造成疲劳，直接损害力量 |
| 低强度有氧独立日 / 空腹 | ✅ 最好 | 零干扰，且低糖原状态零成本 |
| HIIT 独立日，不邻腿日 | ✅ | HIIT 依赖糖原、且与下肢力量抢恢复 |
| HIIT 每周次数 | ≤1-2 次（D） | 恢复预算约束 |

**待核验**：有氧与力量之间的最佳间隔小时数。

## 5. 每周怎么安排休息

**不是"固定休息日"，而是四条约束的解**：

1. **同肌群间隔 1-3 天**，每周该肌群 ≥2 次（ACSM）
2. **每周至少 1 天不做结构化训练**（依从性 + 恢复）——但**步数照走**（休息日不是不动，见 NEAT）
3. **高疲劳日不相邻**：腿日与 HIIT 日不排在一起或连续
4. **减量周由表现与恢复信号触发**，不按日历强制（TP-DELOAD）

**休息日的真实作用**：不是"什么都不做"，而是"不做结构化训练但保持日常活动量"。赤字期 NEAT 自发下降是掉秤停滞的主因，休息日恰恰是它最容易掉下去的时候。

## 6. 训练日 vs 休息日怎么吃

**三个营养素，三种处理方式——这个区分是关键**：

| 营养素 | 是否随训练波动 | 理由 |
|---|---|---|
| **蛋白** | ❌ **每天恒定** | 1.6-2.2 g/kg（减脂期上段）。瘦体重保护需要每日供给，不随训练日调整 |
| **碳水** | ✅ **跟训练走** | 按需供能：糖原依赖型训练日高，休息/低强度日低 |
| **脂肪** | ⚖️ 作为平衡项 | 有下限（约总能量 20%），其余用于填平当日能量 |
| **周总能量** | ❌ 由赤字目标决定 | 不由单日决定——碳循环是**重新分配**，不是加总量 |

**所以"要根据训练计划调整饮食吗"的答案是**：
- **碳水分布：是**（这是按需供能的直接推论）
- **蛋白：不**（恒定）
- **周总能量：不**（由赤字/盈余目标决定）

## 7. 碳循环（低/中/高碳）怎么在一周里分布

### 7.1 先说清两个边界（否则会误导）

**边界一**：碳循环**不产生额外减脂**。等热量等蛋白下低碳无优势（[Hall & Guo](https://www.sciencedirect.com/science/article/pii/S1550413115003502)）。它的正当用途是**按训练需求分配有限的碳水** + 主观饥饿管理。

**边界二**：运动员的碳水标准**不适用于减脂期**。
- [AND/DC/ACSM 联合立场（Thomas 2016）](https://www.jandonline.org/article/S2212-2672(15)01802-X/abstract)：中等运动（1 小时/天）**5-7 g/kg/天**；中高强度（1-3 小时/天）**6-10 g/kg/天**
- **但那是能量平衡下为表现供能的标准**。减脂期总能量被赤字约束、蛋白优先、脂肪有下限，碳水常落在 **2-4 g/kg** 区间
- 所以减脂期的"高碳日"是**相对**概念，不是去够运动员标准

### 7.2 分档依据：当天训练的糖原需求

| 档位 | 用在哪天 | 逻辑 |
|---|---|---|
| **高碳** | 大肌群/高容量力量日（腿日、大复合动作日）、HIIT 日 | 这些工作**依赖糖原**，缺了就掉负荷 |
| **中碳** | 中等容量力量日（上肢、小肌群） | 有糖原需求但较低 |
| **低碳** | 完全休息日、只做低强度有氧的日子 | 低强度有氧不依赖糖原，休息日无糖原消耗 |

### 7.3 一周示例（4 天力量 + 2 天低强度有氧 + 1 天休息）

```
周一  腿（高容量）        → 高碳    ← 糖原需求最大
周二  上肢推              → 中碳
周三  低强度有氧 + 步数   → 低碳    ← 不依赖糖原
周四  下肢/髋主导         → 高碳
周五  上肢拉              → 中碳
周六  低强度有氧 + 步数   → 低碳
周日  完全休息（步数照走）→ 低碳
```

**关键**：周总碳水量 = 赤字预算内的剩余量。高/中/低只是**把这个总量重新分配**到需要的日子，不是往上加。

### 7.4 增肌期的对应版本

盈余下总能量宽松，碳水绝对量更高，但**分布逻辑相同**（训练日高、休息日中）。差别是：
- 低碳日在增肌期没有必要（不需要制造赤字）→ 用"中碳"作为下限
- 盈余幅度小（避免不必要的脂肪增长），瘦者可稍大
