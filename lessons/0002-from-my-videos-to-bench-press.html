MaxPower 视觉验收 · 第 2 课

它认识我的视频，还是认识卧推？

10 分钟学会识别机器视觉里最常见的偷换：把“在见过的素材上成功”说成“理解了一个动作”。

本课唯一目标 以后 Agent 报告“卧推识别成功”时，你能追问一句：成功的是哪一级能力，在哪些从未见过的人和环境上验证过？

SECTION A先拆开三个不同任务

任务系统究竟回答什么MaxPower 当前边界
动作分类画面里是不是卧推，而不是划船或推肩？不要求 用户预先选择动作和机位
动作分段这一组有几次？每次的开始、最低点、结束在哪？部分可用 但泛化与阶段精度未过门禁
动作评估轨迹表现如何？哪些偏差能被画面可靠观察？尚未成立 杠铃轨迹和参考走廊证据不足

所以当前系统并不是看一段任意视频后“认出这是卧推”。产品先告诉它：barbell_bench_press + frontLeft45；系统再用这个特定上下文的规则/参数尝试分段。这是合理的产品选择，但不能被包装成自动理解卧推。

SECTION B“认识卧推”不是开关，而是能力阶梯

  1. 见过的视频能跑通同一批素材既参与观察、调参，又用于汇报结果；只能证明管线可运行。
  2. 你的新视频能识别拍一段 Agent 从未见过的新视频，冻结结果后再揭晓人工答案；证明个人内泛化。
  3. 新人的同场景能识别训练阶段完全没见过这些人，但动作变式、器械和机位固定；证明有限人群泛化。
  4. 跨场景仍能识别新人、新健身房、新手机、不同身材与合理机位均经过分桶验证；才接近产品级卧推识别。
  5. 能做动作质量评估另需人工阶段真值、可靠杠铃轨迹、明确参考范围和“不可判断”边界；不能由计次成绩推出。
关键修正 世界上不存在脱离范围的“真正识别卧推”。可靠说法必须带适用域，例如：在预选杠铃卧推、45° 前侧机位、单人无遮挡、指定手机性能范围内，对未见过的受试者进行逐次分段。

SECTION C用当前证据做一次真实判案

MaxPower 现有一份“盲测”报告曾在 6 条卧推视频上得到 46/46 次匹配，看起来很漂亮。但报告自己写明：杠铃检测器和阈值已经见过这 6 个场景，因此只能证明同语料能力，不能证明对新健身房或新人泛化。

问题仓库证据能否晋级
已见场景能否跑通？6/6 视频，46/46 次匹配可以
同一来源的留出视频？卧推 precision 97.6%，recall 89.1%；所有边界全对的视频为 0%只到局部
未见过的新用户？没有 subject-disjoint 卧推结果不能声称
专业质量建议？客户端无可运行杠铃检测权重；完整三点对齐仅 30.8%不能声称

本案依据：同语料盲测报告、按动作留出评估、客户端验收复盘。

当前最诚实的结论 MaxPower 已有“预先指定动作/机位后，对部分个人视频做卧推计次与阶段分段”的能力证据；还没有“对陌生用户可靠识别卧推”或“理解卧推质量”的证据。

SECTION D你只需向 Agent 索取七张“收据”

  1. 能力声明：是在分类动作、数次数、找阶段，还是评动作？只准写一个。
  2. 适用范围：动作变式、器械、机位、遮挡、设备和用户范围是什么？
  3. 测试隔离：被测的人、原视频和拍摄 session 是否从未参与训练、调参或阈值选择？
  4. 人工真值：谁标了每次的 start / turnaround / end？没有标什么就不能验收什么。
  5. 完整指标：同时看 precision、recall、整组全对率、阶段误差和失败数，不能只挑最好看的一个。
  6. 失败分桶：正面/45°、镜子/无镜子、遮挡/无遮挡、新人/本人分别怎样？平均数会隐藏崩溃场景。
  7. 生产同链：评估是否使用手机端真正运行的模型、单次因果输入和同一版本？离线脚本不能冒充客户端能力。

SECTION F检验一下

1 · Agent 在参与过调参的 6 条视频上做到 46/46 次匹配，这能证明它识别陌生人的卧推吗？

2 · Agent 说它测试了“昨天新拍的视频”，但没有给人工标签和预测文件。现在能下结论吗？

SECTION G下一次直接这样要求 Agent

验收指令 不要证明“卧推识别有效”。先写清本轮只验证哪一级能力；冻结训练/调参所见的人、视频和 session 清单；用从未见过的用户与场景先生成不可修改的预测，再揭晓人工真值。按用户、机位、遮挡分别报告 precision、recall、整组全对率和 start/turnaround/end 误差。任何未验证能力必须写 unmeasured 或 cannot_judge，不得从计次推断动作质量。

推荐先读的一手资料与完整研究笔记：视觉动作识别与 Agent 审核研究。速查版：“我的视频 vs 真正动作”验收卡。
