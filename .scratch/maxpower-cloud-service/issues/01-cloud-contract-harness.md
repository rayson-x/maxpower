**Blocked by:** None — can start immediately.

**Status:** completed

- [x] 新 ADR 明确客户端拥有 reasoning/Policy/工具提议，云端拥有用户确认后的规范资源。
- [x] 服务端可独立安装、启动并返回健康状态与统一错误 envelope。
- [x] HTTP、Identity、ProductData、MediaLibrary、LlmGateway seam 有可运行的 contract tests。
