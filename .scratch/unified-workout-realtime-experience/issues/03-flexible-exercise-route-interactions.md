# 03 — 灵活训练路线与现场增删改切

**What to build:** 用户可以根据器械占用和现场节奏，在今日动作路线上切换、添加、重选、移除、撤销和排序动作，计划提供方向但不限制真实执行顺序。

**Blocked by:** 02 — 当前组卡片、实际组记录与翻转历史。

**Status:** in-progress

- [ ] 点击动作行和左右滑动当前卡片都能切换当前动作，并保留所有动作已经填写或确认的内容。
- [x] 动作管理提供明确重选入口；用户可以为本次训练添加动作，而不自动改变长期计划。
- [ ] 左滑达到明确水平意图后只展开“移除”，用户再次点击才执行；移除后提供可用的撤销入口。
- [ ] 小幅横向抖动不会触发移除或卡片切换，纵向滚动、横滑和长按排序具有互斥方向锁。
- [ ] 长按达到意图阈值后动作产生抬起反馈，可上下拖动；相邻动作以位置让位动画响应，松手后落位并保存今日顺序。
- [ ] 开启减少动态效果时提供不依赖大幅动画的等价反馈；关键触控目标和屏幕阅读标签满足训练环境操作要求。
- [x] 删除、排序或切换动作不会删除已确认 SetOutcome；至少保留一个动作或允许用户明确结束训练。
