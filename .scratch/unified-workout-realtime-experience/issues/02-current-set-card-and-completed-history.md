# 02 — 当前组卡片、实际组记录与翻转历史

**What to build:** 用户在统一当前组卡片上查看目标、调整本组重量和次数、确认实际完成并进入休息；卡片右上角用“已完成 N 组 + 翻转图标”打开背面，逐组查看实际重量、次数及递进递减变化。

**Blocked by:** 01 — 统一训练入口与会话恢复。

**Status:** in-progress

- [x] 正面展示当前动作、本组执行重量、目标次数、RIR 与休息建议；临场编辑只改变本组执行草稿，不静默修改长期计划。
- [x] 正常手动完成进入一次 Set Review，用户确认后才生成 SetOutcome 并启动休息。
- [x] 卡片只显示“已完成 N 组”或“尚未记录”，不显示 `2/5` 等已完成与计划总数组合比例。
- [ ] 有完成记录时，右上角状态与翻转图标共同构成可访问按钮；无记录时不提供空白翻转。
- [x] 背面按确认顺序展示每组 actual load × reps，并标记相对上一组的加重、减重、持平及次数变化；新增 SetOutcome 后即时更新。
- [ ] 背面不混入计划组、未完成组、相机估算重量或未确认观察；翻转不改变当前 set 和草稿。
- [ ] 正反面只有可见面可点击和进入无障碍焦点；卡片无投影，与既有平面卡片组件保持一致。
