# 06 — 执行连续性与平台期诊断

**What to build:** 系统把实际能量路径、饮食/关键训练完成、连续失败、趋势和记录覆盖纳入风险；体重与围度停滞被正确区分为噪声、执行不足、候选平台期或恢复不可持续。

**Blocked by:** 04 — 减脂目标合同与基础风险状态.

**Status:** ready-for-agent

- [ ] 单次失误、连续关键失败、恶化失败率和低记录覆盖产生不同风险结果；未记录不自动等于失败。
- [ ] 联合趋势和测量协议决定是否进入平台诊断；体重平而腰围变化不会被判为平台。
- [ ] 高质量执行下的候选平台期只生成一个可验证、未来生效、可确认的变量调整，而恢复下降时不会自动强化计划。
