# 10 — 可回放 Agent 评估与全链路验收

**What to build:** 产品团队可用同一 Timeline 快照、版本钉和脚本化模型重放 Agent 行为，并量化漏判、过度触发、工具误选、提案采纳和后续结果。

**Blocked by:** 05 — 风险触发的动态计划提案与确认; 06 — 执行连续性与平台期诊断; 07 — 增肌与塑形目标的专用风险模式; 08 — 实时训练闭环与 Timeline 最终沉淀; 09 — 可解释规划进度、知识引用与用户卡片.

**Status:** ready-for-agent

- [ ] 同一事实快照、Goal contract、规则/知识版本稳定重放同一确定性风险和计划校验结果。
- [ ] 场景集覆盖表达变化、聚餐、睡眠差、连续缺训、平台期、实时最终结果、过期提案和通知抑制。
- [ ] 验收报告包含触发延迟、跳过/合并原因、工具选择、提案接受/执行和后续关联结果，且不使用思维链作为评估依据。
