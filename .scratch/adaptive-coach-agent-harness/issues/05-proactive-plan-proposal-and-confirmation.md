# 05 — 风险触发的动态计划提案与确认

**What to build:** 当 Timeline 事实使原目标路径 at risk 时，首页 Agent 主动生成最小扰动的未来计划提案；用户理解理由和代价后确认，才形成新的 Plan revision。

**Blocked by:** 02 — 本地 Agent 工具循环与能力合同; 03 — TimelineChanged 风险触发与定时检查; 04 — 减脂目标合同与基础风险状态.

**Status:** wontfix

- [ ] 对话报告或手动记录的风险事件都可产生待确认提案，不依赖用户会说“重规划”。
- [ ] 提案比较保持当前路径和安全候选路径；无安全候选时展示日期/目标/执行负担取舍，不自动加严或放慢。
- [ ] 事实版本、规则版本或 Goal contract 改变后，旧提案无法提交；拒绝/编辑不会改写现行 Plan revision。
