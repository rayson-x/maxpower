# 03 — 策略集数据化 + Session 组装器

**What to build:** 编排策略集（分化模板库、主项-辅助-孤立三层架构、各级课表模板、组成本模型）从 Markdown 变成知识包 JSON 数据资源（沿用知识包版本化/签名/加载机制）。Session 生成器用知识驱动的组装器替代静态轮换表：按用户目标/经验/可用天数选分化轮转模板（2-3 天全身、4 天上下肢、4-6 天 PPL、偏好时三分化轮转 胸+三头/背+二头/肩+腿），按周量目标（TP-VOL-BASE 分档，增肌默认每肌群每周 4-8 直接组）生成完整推荐方案并附预计时长（标注为估算，时间不强制裁剪；时间明显不够给完整/精简档位由用户选择），逐动作查规则包定次数区间/RIR 区间/负荷锚定/休息建议。75 分钟×每周 3 天的增肌新用户应得到全身×3、每肌群约 6 直接组/周、每课 5-6 个动作的计划，而不是 3 动作×2 组。

**Blocked by:** 02. 数据断桥修复与重排语义

**Status:** ready-for-agent

- [ ] 策略集内容（分化模板/三层架构/课表模板/组成本）进知识包 JSON 且通过签名/hash 校验，随包版本化更新
- [ ] 3 天/周 → 全身 ×3，每肌群每周 ≥2 次暴露、约 6 直接组（TP-VOL-BASE 起步区间）
- [ ] 75 分钟输入产出完整方案 + 预计时长（估算标注）；不再按 maxSlots 静默裁剪
- [ ] 三分化轮转模板可用：胸+三头/背+二头/肩+腿，练 3 休 1 时每肌群约 1.75 次/周且周量下限达标
- [ ] 无确认历史 → 校准语义（RIR 4-5、负荷 unknown 或保守锚点）；有历史 → 按上次表现锚定
- [ ] 周量账本：每个肌群的每周直接组数可计算、可断言
- [ ] 静态 sessionTemplates 轮换表退役，既有 planner 测试更新后全绿
