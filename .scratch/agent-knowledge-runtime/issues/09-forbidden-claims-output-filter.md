# 09 — 禁止声称输出过滤器

**What to build:** 在 provider 流 → UI 投影之间加确定性输出过滤器：命中禁止声称清单（初始内容来自 wiki 三张知识页的明文化清单）时拦截并替换为固定安全文案；拦截事件落 ToolAudit/action log。清单与领域锚定词表同为版本化数据、存知识包随包更新。近义正常用语（如"燃烧脂肪"的日常解释）不误伤。

**Blocked by:** 02. 知识包数据化与加载器

**Status:** ready-for-agent

- [ ] 禁止声称清单逐条有拦截用例（"燃脂次数区间""HRV 表明你生病了""深睡不足会受伤"等）
- [ ] 误伤用例：正常生理学科普表述不被拦截
- [ ] 拦截替换为固定安全文案且事件落审计
- [ ] 清单版本化存知识包，随包更新生效
