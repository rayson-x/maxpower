# 06 — 多周记录形成可信趋势与个人能量校准

**What to build:** 用户可以查看日、周、月的能量、营养、活动、训练、身体和恢复趋势；只有确认的摄入数值覆盖充分、身体测量可比且观察时间足够时，系统才逐步校准个人维持消耗范围。更多低质量信息只扩大不确定性。

**Blocked by:** 03 — 用户手填营养数值后看到完整营养汇总; 05 — 无计划用户完成一次完整自由训练.

**Status:** completed

## Existing foundation and required change

- 保留 Timeline 的事实、更正历史、Daily Health Ledger 和现有身体趋势中符合测量语义的部分。
- 将分散趋势、维护热量估算和局部 calibration 收敛为同一滚动投影与版本化校准规则。
- 删除绕过 Daily Health Ledger 重新汇总能量、营养、训练或身体趋势的路径。

## Acceptance criteria

- [x] 日、周、月展示每日与滚动热量差、宏量、已确认微量营养、活动、训练和身体趋势。
- [x] 食物名称或份量记录不提高 nutrient coverage；只有确认 numeric input 参与摄入覆盖与校准。
- [x] 单日社交饮食、体重波动或训练变化不会被解释为长期趋势。
- [x] 低覆盖、观察期不足或测量协议不可比时不移动个人维持估算。
- [x] 合格多周数据生成带事实前沿、证据窗口、规则版本和不确定性的校准结果。
- [x] 新校准影响后续计算和规划，但不改写历史 Record、Ledger 或旧估算版本。
- [x] record-first 用户没有隐含观察合同，不因缺少记录产生执行失败或追踪提醒。
- [x] 补录、更正和测量协议变化产生确定且可重放的新趋势结果。
- [x] 默认客户端覆盖低覆盖、充分覆盖、噪声测量、有效校准和更正回放。
- [x] 旧趋势计算、维护热量旁路和重复校准模型同次删除。
