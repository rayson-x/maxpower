# 02 — 四项 Baseline intake 共享草稿闭环

**What to build:** 新用户在自然问候后，通过一张只包含年龄、身高、当前体重和自由语言目标的卡片，或直接通过自然语言，完成同一份可恢复 Onboarding draft；产品不再用未经确认的默认值代替用户输入。

**Blocked by:** 01 — 账号档案门控与建档恢复

**Status:** ready-for-agent

- [ ] 首次卡片恰好包含四项全局固定必填：年龄、身高、当前体重和自由语言目标；没有训练等级、训练频率、场地或协作模式等隐藏固定必填。
- [ ] 年龄采用受限数字输入并保存采集时间；由年龄计算的出生年份只作为候选范围，不成为确认事实。
- [ ] 身高和体重使用带单位的数字输入，支持允许的常用单位并在本地规范化；非法范围、空值和单位冲突有可修正反馈。
- [ ] 目标使用可自然表达完整意图的多行文本输入，不被初始 UI 限制为目标枚举。
- [ ] 用户用一条自然语言提供四项时，卡片实时呈现相同草稿值；卡片修改也进入 Agent 下一轮上下文。
- [ ] 每个草稿值保留字段级来源、状态、版本和 supersession；对话与表单不会浅合并覆盖同一 section 的其他值。
- [ ] 重试、断流和恢复不会重复追加等价字段事件，也不会注入页面默认值。
