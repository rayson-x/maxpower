# 03 — 自由目标的结构化捕获

**What to build:** Agent 在保留用户目标原话的同时，把可明确识别的目标、当前起点、保护指标和视觉意图写入正确的领域草稿，并让用户能够看见和修正结构化理解。

**Blocked by:** 02 — 四项 Baseline intake 共享草稿闭环

**Status:** ready-for-agent

- [ ] 目标原话和来源消息始终可追溯，结构化字段不能替代或重写原始叙述。
- [ ] “想把体脂率降到12%，目前16%”产生目标体脂 12% 和当前自报体脂 16% 两个不同所有者的草稿项；当前测量进入 Timeline baseline draft，测量方法保持 unknown。
- [ ] “宽肩窄腰”“减脂时保持卧推”“可以慢一点”等表达分别映射为可复核的视觉目标、保护指标或目标取舍，不压缩成单一粗糙枚举。
- [ ] 用户明确陈述、规范化映射、系统估计和无法判断的内容使用不同状态；任何估计不得覆盖用户自报值。
- [ ] 新表述与现有目标、起点或期限冲突时保留双方来源并进入冲突解决，不静默采用最后一条消息。
- [ ] 相同语义的不同自然语言表达形成等价领域结果，并保留各自的捕获审计。
