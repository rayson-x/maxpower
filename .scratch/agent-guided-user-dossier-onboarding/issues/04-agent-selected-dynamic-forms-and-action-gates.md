# 04 — Agent 动态表单与行动门槛

**What to build:** Baseline intake 完成后，Agent 根据用户目标、当前草稿、审核知识和具体行动门槛，从产品拥有的 Field Catalog 中选择本轮值得询问的字段，并发送与字段语义匹配的小型表单；未知信息只限制真正依赖它的行动。

**Blocked by:** 03 — 自由目标的结构化捕获

**Status:** wontfix

- [ ] Field Catalog 为每个字段定义稳定 ID、领域所有者、值类型、单位、范围、选项、空值/unknown 语义、校验、写入命令、敏感性、展示信息和 `requiredFor`，并可版本化审计。
- [ ] 字段定义明确交互控件，而不是由 LLM 临时决定：自由叙述使用文本区；精确数值使用数字和单位输入；互斥枚举使用单选；可并存选项使用多选；日期/时间使用相应选择器；有明确上下界且允许近似表达的主观连续量才使用分段或滑动控件。
- [ ] 滑动控件必须显示当前值、刻度含义、最小/最大值、步长和可访问的增减/键盘替代方式；不得用于需要精确录入的重量、围度、热量或训练组表现。
- [ ] 复合训练记录能以字段组合收集动作变式、重量、次数、RIR/RPE、日期和条件，不把多个语义压成一个自由文本值。
- [ ] Agent 只能选择 Field Catalog 已注册的字段、主题和顺序；未知字段、模型生成枚举、模型生成单位或不匹配的控件请求在本地被拒绝。
- [ ] 表单提交与对话捕获写入同一 Onboarding draft，并携带 catalog/card/submission 版本；旧卡片提交按版本检测 stale，不能覆盖新值。
- [ ] 追问只在缺失事实会改变一个具体可观察决策时发生，并记录 `goal_disambiguation`、`planning_gate`、`safety_gate`、`measurement_quality`、`schedule_feasibility` 或 `conflict_resolution` 等闭集原因。
- [ ] 用户可以跳过非 Baseline 字段或明确回答不知道；系统记录 explicit unknown，说明受限的具体行动，并抑制没有新理由的重复追问。
- [ ] 至少两个不同目标在同档案条件下选择不同字段组合；已知信息不会重复出现，单张卡片保持一个连贯主题和可完成的交互负担。
