先分清识别、完成度和质量，再决定该借鉴哪个项目。

产品问题最低所需证据当前最有价值的杠杆
有没有做、做了几次？动作上下文、人体/器械时序、人工 rep 边界人体＋器械融合、phase anchor、置信度拒判
一次是否完成？start → turnaround → end、ROM、回到起点阶段状态机、器械刚体轨迹、return check
完成得怎么样？逐错误人工真值、可观察 feature、规则阈值错误 taxonomy、evidence → symbol → rule
用了多少肌肉？3D、负重、接触、肌骨模型、EMG/测力验证目前不是前三项的直接提升手段

优先级今天真正值得投入的四类能力

优先借鉴来源带来的能力进入方式
P0Fitness-AQA 思路＋现有器械轨迹更稳的 Rep/phase/完成度杠铃端点、握点、人体联合状态机
P0NS-AQA 分层可解释的逐项质量判断自有标签＋Rust feature/rule/explanation
P1SynthPose/OpenCapBench更精细的关节和躯干观测候选先做离线 teacher A/B，再决定扩 schema
P1Sports2D/Pose2Sim滤波、拒判和独立 3D 参考研究/验收链，不直接进默认运行时

边界不要混成一个“动作分数”

OBSERVED：腕点、肘点、杠铃端点、置信度 ↓ COMPLETION：阶段是否走完、ROM 是否达到、是否回到起点 ↓ QUALITY：路径、稳定、对称、代偿是否满足动作规则 ↓ EXPLANATION：哪条证据触发哪条规则 MUSCLE / FORCE：另一条研究链；不能倒灌成上述真值
验收纪律 “算法看起来更高级”不算提升。必须在相同冻结视频、相同人工真值上，比较 baseline 与 variant 的 Rep precision/recall、阶段误差、整组全对率、质量逐错误 precision/recall 和 cannot_judge 覆盖率。

暂缓当前不直接改善前三项的项目

OpenSim、Nimble、MuscleMimic、MinT、MIA 和 OpenCap dynamics 主要解决动力学、模拟肌肉或 EMG proxy。它们可帮助未来解释负荷，但不会自动修好漏计、阶段偏移、遮挡、错误标签或质量规则。
