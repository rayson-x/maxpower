七张收据少一张，就降低一级

  1. 一句精确、可证伪的能力声明
  2. 动作变式、器械、机位、设备、用户范围
  3. subject / capture / session 均独立的测试清单
  4. 与预测分离保存的人工真值
  5. precision、recall、整组全对率、阶段误差
  6. 按用户、机位、遮挡、镜面拆开的失败表
  7. 与客户端一致的模型、版本、因果运行路径

红旗听到这些话立刻停

Agent 的话你该问什么
“准确率 95%”分母是什么？precision 还是 recall？测试用户见过吗？
“用了盲测”模型、阈值和检测器是否都在揭晓真值前冻结？
“支持卧推”是预选上下文后的计次，还是自动动作分类？
“杠铃轨迹改善结果”客户端真的运行检测器了吗，还是只在离线脚本里？
“能给动作建议”哪些建议有人工质量标签和未见用户验证？
“再调一下阈值就好”用哪条训练视频调？哪条冻结视频只验不调？

可信汇报格式让 Agent 只填空
